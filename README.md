## Installation

Each module is a standalone Odoo addon. To install:

1. Clone this repository or copy the desired module folder into your
   Odoo addons path.
2. Update the apps list in Odoo (`Apps → Update Apps List`).
3. Install the module from the Apps menu.

For odoo.sh deployments, add this repository as a submodule of your
project repository, or copy individual modules into your project.

## Compatibility

Modules are tested against Odoo Community and Enterprise editions for
the version matching the branch they live in.
